# 🎓 파이썬 과제 자동 채점 프로그램 (Homework Grader)

교사가 배포한 원본 소스코드와 학생들이 제출한 주피터 노트북(`.ipynb`) 과제를 비교하여, 코드를 전혀 수정하지 않고 그대로 제출한 경우 `0점`, 코드를 실제로 수정한 경우 `1점`을 부여하여 하나의 엑셀 성적표에 열(Column)로 누적 기록해주는 자동 채점 도구입니다.

---

## 🌟 주요 기능

1. **스마트 코드 비교 (AST 분석)**
   - 단순 줄바꿈, 공백, 주석(`# ...`)만 추가/수정한 학생은 **0점(미수정)**으로 정확히 판별합니다.
   - 실제 파이썬 코드 로직, 변수, 함수 등이 수정된 경우에만 **1점(수정 인정)**을 부여합니다.
2. **다회차 열(Column) 누적 관리**
   - 회차별 과제를 채점할 때마다 하나의 엑셀 파일 오른쪽에 새로운 과제명 열이 계속 추가됩니다.
   - 기존 과제를 다시 채점하면 중복 열을 만들지 않고 기존 열의 점수를 최신으로 갱신합니다.
3. **유연한 채점 모드 선택**
   - **스마트 비교 모드 (`smart`)**: 코드 수정 여부를 검사하여 1점 부여
   - **제출자 전원 인정 모드 (`all`)**: 출제 오류나 단순 제출 확인 과제 시, 제출자 전원 1점 부여 (미제출만 0점)
4. **주피터 노트북 완벽 지원**
   - `.ipynb` 및 다운로드 시 확장자가 붙은 `.ipynb.txt` 파일 내부의 순수 코드 셀(`code`)만 추출하여 비교합니다.
5. **데이터 안전 백업**
   - 엑셀 파일을 갱신하기 전 자동으로 백업 파일(`.bak`)을 생성하여 실수를 방지합니다.

## 📁 추천 폴더 구조

```text
homework/
 ├── homework_grader.py           # 채점 프로그램
 ├── 수강생.xlsx                   # [통합 엑셀] 모든 회차 점수가 누적되는 성적표
 │
 ├── sources/                     # [교사용] 배포했던 원본 코드 보관소
 │    ├── 10.19_source.ipynb
 │    └── 10.28_source.ipynb
 │
 └── submissions/                 # [학생 제출용] 회차별 학생 과제 폴더
      ├── 10_19과제/
      │    └── 학번_이름_*.ipynb
      └── 10_28과제/
           └── 학번_이름_*.ipynb
```

## 🚀 시작하기

### 1. 필수 라이브러리 설치
```bash
pip install openpyxl
```

### 2. 실행 방법

#### 방법 A: 대화형 실행 (질문에 엔터로 진행)
```bash
python homework_grader.py
```

#### 방법 B: 한 줄 명령어로 실행
```bash
# 1) 스마트 비교 모드 (수정자만 1점)
python homework_grader.py "submissions/10_28과제" "sources/10.28_source.ipynb" "수강생.xlsx" "10_28과제" smart

# 2) 제출자 전원 점수 부여 모드 (제출자 모두 1점)
python homework_grader.py "submissions/10_19과제" "sources/10.19_source.ipynb" "수강생.xlsx" "10_19과제" all
```
